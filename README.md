# TAIGA — бурки из оленьей шкуры

Сайт бренда TAIGA: бурки ручной работы из натуральной оленьей шкуры.

**Сайт:** https://esrudenko.github.io/taiga-site/

## Страницы

- **Главная** (`index.html`): о бренде, индивидуальный пошив, доставка и сроки, контакты.
- **Каталог** (`catalog.html`): женские, мужские и детские бурки. У каждой модели галерея (миниатюры, свайп, полноэкранный просмотр), цена в ₸ / ₽ / $ и кнопка заказа. Есть инструкция «Как снять мерки» со схемами.

## Возможности

- Светлая и тёмная темы. Выбор темы сохраняется, фото тоже меняются под тему.
- Адаптивная вёрстка от 320px, бургер-меню.
- Форма заявки в модальном окне с проверкой полей. Заявки отправляются в Telegram.
- Доступность: управление с клавиатуры, `focus-visible`, подписи у кнопок-иконок, закрытие окон по Escape, ссылка «Перейти к содержанию».
- Фото в WebP, ленивая загрузка изображений ниже первого экрана.
- SEO: свои заголовки и описания у страниц, Open Graph.

## Технологии

HTML, CSS, JavaScript без фреймворков и сборки.

```
css/      стили по компонентам (variables, base, header, hero, …)
js/       скрипты по функциям (theme, menu, request-form, catalog, …)
img/      изображения (WebP)
server/   Cloudflare Worker для отправки заявок в Telegram
```

## Как подключить отправку заявок в Telegram

Токен бота нельзя хранить в коде сайта, поэтому заявки проходят через небольшой бесплатный сервер на Cloudflare Workers.

1. В Telegram напишите [@BotFather](https://t.me/BotFather), выполните `/newbot` и сохраните **токен** бота.
2. Напишите своему боту любое сообщение. Затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": …}`. Это **CHAT_ID**.
3. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com), откройте **Workers & Pages → Create → Worker**, вставьте код из `server/telegram-worker.js` и нажмите **Deploy**.
4. В настройках воркера (**Settings → Variables and Secrets**) добавьте:
   - `BOT_TOKEN`: токен из шага 1 (тип **Secret**);
   - `CHAT_ID`: id из шага 2;
   - `ALLOWED_ORIGIN`: `https://esrudenko.github.io`.
5. Скопируйте адрес воркера (вида `https://….workers.dev`) и вставьте его в `js/request-form.js`:

   ```js
   const REQUEST_ENDPOINT = "https://….workers.dev";
   ```

Пока адрес не указан, форма не показывает ложный «успех»: она сообщает, что заявку отправить не удалось, и предлагает написать в WhatsApp.
