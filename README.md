# TAIGA — бурки из оленьей шкуры

Сайт бренда TAIGA: бурки ручной работы из натуральной оленьей шкуры.

**Сайт:** https://taiga-burki.kz/

## Страницы

- **Главная** (`index.html`): о бренде, индивидуальный пошив, доставка и сроки, контакты.
- **Политика конфиденциальности** (`privacy.html`).
- **Каталог** (`catalog.html`): женские, мужские и детские бурки. У каждой модели галерея (миниатюры, свайп, полноэкранный просмотр), цена в ₸ / ₽ / $ и кнопка заказа. Есть инструкция «Как снять мерки» со схемами.

## Возможности

- Светлая и тёмная темы. Выбор темы сохраняется, фото тоже меняются под тему.
- Адаптивная вёрстка от 320px, бургер-меню.
- Форма заявки в модальном окне с проверкой полей. Заявки отправляются в Telegram.
- Доступность: управление с клавиатуры, `focus-visible`, подписи у кнопок-иконок, закрытие окон по Escape, ссылка «Перейти к содержанию».
- Фото в WebP, ленивая загрузка изображений ниже первого экрана, шрифты загружаются с самого сайта (без Google Fonts).
- SEO: свои заголовки и описания у страниц, Open Graph.

## Технологии

HTML, CSS, JavaScript без фреймворков и сборки.

```
css/      стили по компонентам (variables, base, header, hero, …)
js/       скрипты по функциям (theme, menu, request-form, catalog, …)
img/      изображения (WebP)
fonts/    шрифты (woff2)
server/   серверный код отправки заявок
```

## Отправка заявок

Заявка из формы уходит на `server/send.php`. Он пересылает её владельцу в Telegram (через бота) и копией на почту. Токен бота нельзя хранить в коде страницы, поэтому нужен этот серверный посредник. Хостинг выбран в Казахстане, потому что в России ограничены и Cloudflare, и Telegram.

`send.php` проверяет согласие на обработку данных, отсеивает спам-ботов (скрытое поле-ловушка и слишком быструю отправку) и ограничивает частоту: не больше 5 заявок за 10 минут с одного адреса. «Спасибо» на сайте появляется только после того, как сервер подтвердил доставку.

### Установка на хостинг

Нужен хостинг с PHP 8+, cURL и разрешёнными исходящими HTTPS-запросами.

1. Загрузить все файлы сайта в корень сайта на хостинге (обычно `public_html`), вместе с папкой `server/`.
2. В папке `server/` скопировать `config.example.php` в `config.php` и заполнить:
   - `telegram_token`: токен бота от @BotFather;
   - `telegram_chat_id`: chat id получателя (его показывает `https://api.telegram.org/bot<ТОКЕН>/getUpdates` после того, как получатель нажал «Start» в боте);
   - `email_to`: почта для копий заявок;
   - `email_from`: адрес отправителя на домене сайта, например `no-reply@домен`;
   - `salt`: любая случайная строка.
3. Отправить тестовую заявку с сайта и убедиться, что она пришла в Telegram и на почту.

`config.php` не хранится в git (указан в `.gitignore`), а `server/.htaccess` закрывает к нему доступ из браузера. Если токен утёк, его нужно сменить в @BotFather командой `/revoke` и вписать новый в `config.php`.

Пока сайт лежит на GitHub Pages, PHP там не работает. Поэтому форма показывает сообщение, что заявку отправить не удалось, и предлагает написать в WhatsApp.
